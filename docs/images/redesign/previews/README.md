# Design kit previews

Downscaled JPG previews (max 1600 px) of the design kit's PNG exports, used to embed visual references in GitHub issues and reviews. The original 2× PNG exports are in `../images/` (screens and component boards) and `../assets/brand/` (logo PNGs).

- `screens/`: screen mockups. Best references: `design_kit_light_2x.jpg`, `design_kit_dark_menu_2x.jpg`, `foundation_concept_2x.jpg`. The others are older AI mockups (some still branded "TalentMate"): layout hints only; tokens and component specs win (`../docs/handoff/MOCKUP-DEVIATIONS.md`).
- `components/`: component state boards (light/dark). Icons render as empty boxes there because the icon font was missing at export time.
