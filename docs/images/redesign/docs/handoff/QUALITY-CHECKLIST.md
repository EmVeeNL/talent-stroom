# UI QA checklist

- [ ] Asap Sharp daadwerkelijk geladen (geen FOUT/FOIT issues).
- [ ] Material Symbols Rounded glyphs zichtbaar, en iconnamen exact.
- [ ] Alle body- en controls voldoen aan contrastregels.
- [ ] Focus ring helder, keyboard focus trap dialog, Escape menu close.
- [ ] Light/dark geen onbedoeld merkverschil; systeemthema werkt.
- [ ] Check hover/focus/disabled/error in Playwright.
- [ ] Tabellen bij 390px bruikbaar, desktop 1440px density correct.
- [ ] Data is niet gelekt tijdens organization switch.
- [ ] Schermrender bij DPR 1/2/3, browser zoom 200%.
- [ ] Icon-only buttons hebben `aria-label`.
- [ ] Empty/loading/error onderscheiden.
- [ ] Screenshots bevatten geen echte persoonsgegevens.
