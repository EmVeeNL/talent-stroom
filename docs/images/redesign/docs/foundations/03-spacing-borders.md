# Spacing, borders, radius, elevatie

## Spacing
4px-baseline met ondersteunende stappen `2, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80`. Default component gap 8 of 12px, card padding 20–24px, form gap 16px, paginamarges 24px desktop / 16px mobiel.

## Randen & vormen
Border 1px `--color-line`. Focus ring 2px met extra zichtbare offset. Radius: `sm=6`, `md=10`, `lg=14`, `xl=20`, `full=9999` px. Inputs 10px; buttons 10px; cards 14px; modal 20px.

## Shadows
Light cards: `0 3px 12px rgb(16 32 56 / .06)`. Popover: `0 12px 36px rgb(16 32 56 / .16)`. Dark: minimale schaduw, zichtbare border en surface elevation. Vermijd intense glow-effecten als standaard.

## Layout
Sidebar 252px expanded / 68px collapsed. Navbar 64px. Content max 1600px met responsive grid. Minimum interactive hit area 44×44px waar haalbaar; bij compacte tabellen 36px alleen met passend toegankelijk alternatief.
