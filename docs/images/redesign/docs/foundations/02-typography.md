# Typografie — Asap Sharp

Gebruik de reeds geïnstalleerde **Asap Sharp** (fonts worden niet herverdeeld). CSS `font-family: "Asap Sharp", sans-serif` via Tailwind v4 `--font-sans`.

| Rol | Grootte/line-height | Weight |
|---|---|---|
| Hero | 36/44 px | 700 |
| Page title | 30/38 px | 700 |
| Section heading | 24/32 px | 700 |
| Card title | 18/26 px | 600 |
| Body | 16/24 px | 400 |
| Table / compact body | 14/20 px | 400–600 |
| Caption | 12/16 px | 400 |
| Label | 14/20 px | 600 |

Geen echte data als afbeelding van tekst opleveren. Gebruik tabular-nums bij KPI's en valuta; expliciete line-height en voldoende ruimte voor Nederlandse woorden. Browser zoom 200% controleren.
